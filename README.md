### Jimmy · [Holdout](https://holdout.cc)

I audit RL environments and agent benchmarks for reward hacks and grader bugs: places where an agent can score well without doing the task, or where correct work is scored as wrong.

- [holdout-findings](https://github.com/holdout-cc/holdout-findings): issues filed in public RL environments and benchmarks, with reproductions and dated issue status
- [reward-hack-patterns](https://github.com/holdout-cc/reward-hack-patterns): common grader failure patterns, each with a runnable example and a fix
- [grader-probe](https://github.com/holdout-cc/grader-probe): a small tool that checks reward functions for false credit and false rejection
